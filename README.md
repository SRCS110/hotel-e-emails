# Hotel E — 2026 Email Campaign Tool

Internal tool for previewing, editing, and downloading the 12-month Hotel E Santa Rosa email campaign.

## Features
- Preview all 12 monthly emails
- Click-to-edit any text inline (subject line, copy, events, CTAs)
- Download each month as production-ready HTML for Mailchimp
- Download all 12 at once

## Local development

```bash
npm install
npm run dev
```

## Deploy on Vercel
1. Push this repo to GitHub
2. Go to vercel.com → Add New Project → Import this repo
3. Leave all settings as default — Vercel auto-detects Vite
4. Click Deploy
